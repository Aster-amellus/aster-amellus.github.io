好啦讓花點時間去挑戰 MLIR Dialect，不再討論這個無聊的 AST。

讲 Ch2 的内容之前我觉得应该去了解一下这章的一个核心概念： TableGen。这里的核心是写一套 Ops.td（也可以是各种*.td文件）的 TableGen 文件然后用 TableGen 去生成。

嗯那 TableGen 文件怎么写呢？可以看 llvm 官网的介绍 和 TableGen Programmer’s Ref。总而言之这是一种声明式的 DSL(Domain Specific Language)，可以理解成 Record class 和一系列根据 class 来定义的 def + 强而有力的 backend来解析各种生成的 Record。比如说下面这个例子世界上就是三个自己定义的 Record，它经过backend解析后（比如RegisterInfo）才能把这里的 Record 解释成寄存器。

TableGen 也是有一套完整的类型系统的

我们抄一下 llvm 里的比较关键的几个定义： string

  • string 类型表示一个任意长度的有序字符序列。 code
  • 关键字 code 是 string 的别名，可用于表示代码中的字符串值。 bits<n>
  • bits 类型是一种固定大小的整数，其任意长度 n 被视作独立的位。这些位可以单独访问。该类型的字段适用于表示指令操作码、寄存器编号或地址模式/寄存器/偏移量。字段的位可以单独设置，也可以作为子字段设置。例如，在指令地址中，寻址模式、基址寄存器编号和偏移量可以分别设置。 list<type>
  • 此类型表示一个列表，其元素类型由尖括号中指定的类型决定。元素类型可以是任意类型，甚至可以是另一个列表类型。列表元素的索引从 0 开始。 dag
  • 此类型表示一个可嵌套的有向无环图（DAG）节点。每个节点都有一个操作符以及零个或多个参数（或操作数）。参数可以是另一个 dag 对象，从而允许构建任意节点和边的树形结构。例如，DAG 用于表示代码模式，供代码生成器指令选择算法使用。更多详细信息，请参见Directed acyclic graphs (DAGs)。

list<T> 比较容易理解，就是一个同构、有序、可索引的列表。
